# 公开化整理说明

本仓库是独立整理的公开版本，不包含研究工作区的历史、原始采集结果、宿主配置、截图、第三方应用及其修改版本。

保留与调整：

- 解释器核心和控制台、图形控制台、文件与文本命令实现；通用控制台工具模块使用 `console_tools` 名称。
- 独立的语法、运行时、编码、终端、GUI、诊断、鼠标、延时与管道回归测试。
- 34 个核心用例、121 条冻结行为观察，保留标准输出/错误的精确字节、返回码、文件内容摘要和 DOS 属性；去除来源路径、采集标识、时间戳及其他与断言无关的元数据。
- 38 条独立宏展开和管道观察，仅保留最小脚本及行为预期。条件分支用例使用通用变量和常量。
- 原有依赖外部应用的端到端测试改为合成的输入、算术、递归调用和时间格式测试；不再声称覆盖那些应用的完整功能。
- 原始采集器及其归档一致性测试不纳入公开版，因为它们验证的是私有研究材料。公开版保留行为测试，不宣称复现研究工作区的全部基线。
- 内置命令帮助改为项目自行编写的说明，保持静态包数据加载方式和既有帮助返回码。

测试中的虚拟系统版本、固定日期、保留地址和临时目录用于验证行为，并非开发者真实配置。独立 stream helper 只输出固定字节，不读取环境或机器配置。

`tools/check_public_tree.py` 检查公开文件类型、常见敏感路径、密钥模式、禁止带入的目录，并解码 JSON 中的十六进制数据后检查。此检查作为维护防线，不能代替对新增内容的人工审阅。构建采用明确的包和源码文件清单；wheel 仅包含运行时代码、帮助数据与包元数据。

发布使用 `tools/build_release.py`：除源码内容检查外，还会清除源码归档中的宿主 UID/GID、所有者名称和时间戳，并检查两种归档中的实际内容。直接运行底层构建器可能重新引入归档所有者元数据。
